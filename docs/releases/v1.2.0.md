# Omniworld Launcher 1.2.0

基于 HMCL 的非官方定制版本，采用 mac 风格界面，融合 Omniworld、魔女旅途与魔法元素。

- 全新主题、放大的窗口、魔法阵、流星、鼠标轨迹和点击涟漪。
- 特效支持自动 / 60 / 120 / 144 FPS 设置，以及粒子密度调整。
- 定制 EXE 图标、可爱的猫咪鼠标与轻量点击音效，可在设置中关闭。
- 新建游戏配置默认窗口为 1920 × 1680；已有自定义分辨率保留。
- 默认保持启动器窗口打开，相关功能收纳至设置。
- 修复微软设备登录参数和错误处理。

## 下载与运行

Windows 用户下载 **Omniworld-1.2.0.exe**，或下载完整 **Omniworld-1.2.0-Windows.zip**。EXE 内含启动器程序和资源，仍需电脑安装 Java 17 或更新版本。本版本未附带 Java 运行时。

微软登录需有效且有相应权限的 Microsoft OAuth Client ID，可在登录配置中填写。设备登录已通过本地模拟测试，尚未完成真实微软账号与 Minecraft 启动的端到端验证。

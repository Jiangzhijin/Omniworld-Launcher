# Omniworld Launcher 1.3.0

## 本次更新

- 游戏默认分辨率调整为 **1600 × 900**。旧版保存的 1920 × 1680 会自动迁移，其他自定义尺寸保留。
- 重构账号、下载、游戏管理和高级设置的共享布局：统一导航侧栏、章节标题和内容工作区。
- 统一设置卡片、输入框、下拉菜单、按钮、登录弹窗、资源列表和表格样式。
- 无账号时显示登录引导；安装与导出向导采用统一的章节标题。
- 关于页使用 Omniworld 品牌，同时保留 HMCL 原项目署名；反馈入口指向本定制仓库。

## 下载与升级

Windows 用户可下载 **Omniworld-1.3.0.exe**，或下载 **Omniworld-1.3.0-Windows.zip**。EXE 已包含程序和资源，仍需安装 **Java 17 或更新版本**。

升级前备份原程序，再用新 EXE 替换旧 EXE；保留已有配置和 `.minecraft` 文件夹。SHA256SUMS.txt 可用于核对下载文件。

微软登录仍需有效且有相应权限的公共 Microsoft OAuth Client ID。本版本未进行真实微软账号或实际 Minecraft 启动的端到端验证。

本地已通过分辨率与配置回归测试，并渲染检查账号、下载、游戏库、各设置标签、登录弹窗及真实分辨率菜单；检查了常规与紧凑窗口布局。云端发布流程重新构建 Windows EXE/JAR，并运行配置与 OAuth 回归测试。
